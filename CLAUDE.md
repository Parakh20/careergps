# CLAUDE.md

## Project

Career GPS - Adaptive Decision Support for Career Growth

This app uses Anthropic Claude to help students make informed, ethical, and personalized growth decisions. It is not a static recommendation engine. It should feel like a reflective mentor and systems thinker.

## Claude Setup

Create a `.env` file in the project root:

```bash
CLAUDE_API_KEY=your_claude_api_key_here
CLAUDE_MODEL=claude-haiku-4-5-20251001
```

The API route also accepts `ANTHROPIC_API_KEY` as a fallback environment variable.

## Current Model

```text
claude-haiku-4-5-20251001
```

## Core Purpose

Help users:

- understand their current situation
- answer clarification questions before plan generation
- explore multiple paths
- evaluate tradeoffs
- adjust plans dynamically
- retain full decision-making control

The system must never:

- make decisions for the user
- present a single correct path
- give overconfident predictions
- guarantee success

## How Claude Is Used

Claude is called from:

```text
api/generate-roadmap.js
```

Prompt and schema logic lives in:

```text
src/lib/careerPlan.js
```

The app uses Anthropic's Messages API with tool-based structured output. Claude is forced to call the `create_career_plan` tool, whose `input_schema` matches the adaptive decision-support JSON contract.

The frontend must ask the six clarification questions before calling Claude:

- experience check
- optional project description
- learning preference
- immediate goal
- main blocker
- optional resume text

Adaptive clarification questions are generated by:

```text
api/generate-questions.js
```

The modal flow is:

```text
Form -> Core questions -> Adaptive questions -> Final Claude plan -> Same-page results
```

## Mandatory Behavior

- Show reasoning behind every major suggestion.
- Explicitly state uncertainty.
- Provide multiple paths.
- Highlight risks and failure points.
- Encourage user reflection.
- Adapt the plan if feedback is given.
- Avoid generic outputs and single-path certainty.

## Prompt Constraints

- Exactly 5 skill-gap items
- Exactly 3 tasks per week
- Exactly 2 adaptive changes and 2 adaptive tradeoffs
- Exactly 2 failure scenarios
- Exactly 2 project suggestions
- Exactly 3 assumptions
- Exactly 3 risks
- Exactly 2 alternative paths
- Exactly 3 user decisions and 3 reflection questions
- Adaptation options must be: `Too hard`, `Too easy`, `Not interested`, `Give alternative`

## Troubleshooting

If the app uses the demo fallback:

- Check that `.env` exists.
- Check that `CLAUDE_API_KEY` is set.
- Restart `npm run dev` after editing `.env`.
- Confirm the model ID is available to the key.

If Claude reaches the token limit:

- Keep `max_tokens` high enough in `api/generate-roadmap.js`.
- Keep prompt output constraints compact in `src/lib/careerPlan.js`.

If the model is rejected:

```bash
curl -sS https://api.anthropic.com/v1/models \
  -H "x-api-key: $CLAUDE_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  | jq '.data[].id'
```

Use one of the returned model IDs in `CLAUDE_MODEL`.
